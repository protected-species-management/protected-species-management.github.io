# Extract growth rate

Extracts \\lambda\\ from an `om` object.

## Usage

``` r
lambda(object, ...)

# S4 method for class 'om'
lambda(object, log = FALSE)
```

## Arguments

- object:

  `om` class object

- ...:

  (not used)

- log:

  logical value indication whether \\r = \log(\lambda)\\ should be
  returned.
