# Access or assign phi parameter

Access or assign the \\\phi\\ value used to tune the PST reference
point.

## Usage

``` r
phi(object, ...)

# S4 method for class 'om'
phi(object)

phi(object, ...) <- value

# S4 method for class 'om,numeric'
phi(object) <- value
```

## Arguments

- object:

  `om` class object

- ...:

  arguments for the generic function definition

- value:

  numeric value
