# Load bias

Load bias into
[`om`](https://github.com/protected-species-management/operating-model/om/reference/om-class.md)
class object for stochastic projection.

## Usage

``` r
load_bias(object, value, ...)

# S4 method for class 'om,list'
load_bias(object, value)
```

## Arguments

- object:

  `om` class object

- value:

  named list object containing values for `observation` or `mortality`.

- ...:

  arguments for the generic function definition
